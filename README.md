# chess_db
Chess Database Challenge
📝 وصف المشروع
مشروع تحليل قاعدة بيانات الشطرنج يهدف إلى تدريب الطلاب على استخدام أوامر SQL المتقدمة لاستخراج وتحليل البيانات.
يتكون المشروع من أربع مراحل رئيسية، كل مرحلة تحتوي على مجموعة من المهام العملية التي تغطي أساسيات الاستعلام، التجميع، الربط، واستخدام الدوال النافذة.

🎯 أهداف المشروع
إتقان أوامر SELECT و GROUP BY لتحليل البيانات.

استخدام JOINs و CTEs لدمج الجداول وإنشاء استعلامات معقدة.

تطبيق Window Functions مثل RANK و LAG لفهم البيانات بشكل ديناميكي.

بناء تقارير إحصائية عن الألعاب، اللاعبين، والافتتاحيات.

📂 مراحل المشروع والمهام
🔹 المرحلة 1 — SELECT
Q1: حساب عدد الألعاب الكلي وعدد الألعاب المصنفة.

Q2: عرض جميع قيم victory_status مع عددها.

Q3: استخراج 10 ألعاب بأكبر عدد من النقلات.

Q4: حساب نسبة الفوز للأبيض، الأسود، والتعادل.

Q5: حساب المتوسط والأقصى لعدد النقلات لكل حالة فوز.

Q6: تحديد أكثر 5 افتتاحيات شيوعًا باستخدام HAVING.

🔹 المرحلة 2 — GROUP BY
تطبيق التجميع على بيانات الألعاب لتوليد إحصاءات مفصلة.

🔹 المرحلة 3 — JOINs & CTEs
Q7: ربط جدول الألعاب مع جدول الافتتاحيات واستخراج أكثر 5 افتتاحيات لعبًا.

Q8: استخدام LEFT JOIN لاكتشاف اللاعبين الذين لم يظهروا كـ white_id.

Q9: باستخدام CTE حساب إجمالي انتصارات كل لاعب كأبيض.

Q10: دمج انتصارات الأبيض والأسود في جدول واحد باستخدام UNION CTE.

🔹 المرحلة 4 — Window Functions
Q11: إضافة عمود يوضح ترتيب كل لعبة حسب تقييم اللاعب الأبيض باستخدام RANK.

Q12: استخدام LAG لعرض تقييم اللاعب الأبيض الحالي والسابق لنفس اللاعب (للاعبين الذين لديهم 5+ ألعاب).
